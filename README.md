# 🎨 T-Racers Media Studio

The **official standalone social media creator workspace** for T-Racers MEC — Egypt's pioneering Formula Student team from Tanta University.

## Features

- 🏆 **9-in-1 Achievement Generator** — Post, Story, and Carousel templates
- 🖼️ **Profile & Livery Frame Generator** — Transparent PNG livery frames
- 🎨 **Full Design Control** — Customize colors, positions, sizes, fonts of every element
- 🚀 **Standalone SPA** — Deployed independently on Vercel

## Tech Stack

- **Angular 20** (Standalone, Client-Side SPA)
- **Tailwind CSS v4**
- **html2canvas** for image export

## Development

```bash
npm install
npm start       # dev server at http://localhost:4200
npm run build   # production build
```

## Deployment

Deployed on Vercel. All API calls are automatically proxied to the production backend via `vercel.json`.
